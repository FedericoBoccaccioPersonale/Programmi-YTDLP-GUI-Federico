Poichè la compilazione avviene basandosi sul tag, questa è la procedura per creare un tag da interfaccia web.

1. **Releases** (nella colonna a destra) → **Draft a new release**.
2. Apri il menu **Choose a tag**, scrivi il nome (per esempio `V1.2`) e clicca **Create new tag**.
3. Nel menu **Target** scegli il ramo (`main`).
4. Clicca **Publish release**.

GitHub non permette di creare un tag senza una release: lo conferma una richiesta aperta da molti utenti nella sua community. Puoi spuntare «Set as a pre-release» per non farla passare come versione stabile.
