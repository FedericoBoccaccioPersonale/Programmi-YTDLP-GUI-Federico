# Codice di condotta

L' obiettivo di questo progetto è risolvere un problema tecnico fornendo uno strumento affidabile e robusto.

1. **Concretezza:** Le discussioni nelle Issues e nelle Pull Requests devono rimanere strettamente tecniche e focalizzate sull' argomento. Spero che questa riga sia superflua.
2. **Nessuna scusa:** Se un bug viene confermato, va risolto. Codice scritto male o difetti architetturali vanno rimossi prima della pull request.
3. **Responsabilità:** Prima di aprire un ticket, controlla se il problema dipende dall' aggiornamento di `yt-dlp` stesso (spesso rotto dalle modifiche di YouTube). In tal caso, attendi l' aggiornamento di `yt-dlp`.
4. **Responsabilità 2:** I sottotitoli potrebbero non esistere perché YouTube **si rifiuta** di generarli: è un problema noto e che non hanno mai voluto risolvere; si verifica in particolare per quelli tradotti automaticamente.
5. **Professionalità:** Non sono ammessi linguaggi scurrili, insulti o comportamenti tossici. Mantieni un registro rigorosamente professionale.
