Since compilation is based on the tag, here is the procedure for creating a tag from the web interface.

1. **Releases** (in the right column) → **Draft a new release**.
2. Open the **Choose a tag** menu, type the name (e.g. `V1.2`) and click **Create new tag**.
3. In the **Target** menu select the branch (`main`).
4. Click **Publish release**.

GitHub does not allow creating a tag without a release: this is confirmed by an open request from many users in its community. You can check "Set as a pre-release" to prevent it from being treated as a stable version.
